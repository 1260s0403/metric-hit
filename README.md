# MetricHit OS

Базовый каркас проекта MetricHit OS.

## Структура

- `apps/` — пользовательские приложения и сервисы.
- `knowledge/` — утверждённые, кандидатные и исходные материалы, а также сводки чатов.
- `data/` — локальные данные и импорты (содержимое не коммитится).
- `documents/` — проектные документы.
- `workflows/` — описания рабочих процессов.
- `logs/` — локальные журналы (не коммитятся).
- `scripts/` — служебные сценарии.
- `tests/` — тесты.
- `backups/` — локальные резервные копии (не коммитятся).

Правила работы с репозиторием описаны в `AGENTS.md`.
