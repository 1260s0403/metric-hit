# Решение владельца: стандарт визуального пакета для статей

- Дата решения: 01.09.2026.
- Источник: прямое подтверждение владельца MetricHit.

## Постоянный стандарт

Каждый будущий содержательный черновик статьи получает визуальный пакет по умолчанию: обложку, подходящую целевой площадке, и две поддерживающие иллюстрации. Исключение возможно только по прямому указанию владельца.

Каждая иллюстрация должна:

1. Объяснять конкретный раздел статьи, а не служить декоративной заглушкой.
2. Быть оригинальной и проверенной исполнителем визуально до поставки.
3. Не содержать выдуманных результатов, метрик, кейсов, скриншотов интерфейса, логотипов или клиентских данных.
4. Быть заменена и сгенерирована заново исполнителем, если качество, читаемость или связь с разделом недостаточны.

Для обычного визуального пакета не нужно отдельное согласование владельца. Отдельное решение владельца требуется только для изменения глобального стиля, использования реальных фотографий или логотипов, а также для внешней публикации.
