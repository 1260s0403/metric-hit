# Граница «Ядра» и проекта MetricHit

- Дата решения: 17.08.2026.
- Источник: прямое утверждение владельца MetricHit.

«Ядро» — самостоятельный инфраструктурный продукт и control plane. Оно предоставляет общие возможности памяти, решений, проектов, задач, аудита и управления Strategy.

Внутри «Ядра» существует самостоятельный проект «Развитие Ядра» для работ над самим control plane. MetricHit — первый независимый бизнес-проект под управлением «Ядра». В дальнейшем «Ядро» может управлять несколькими независимыми проектами.

Каждый независимый проект может иметь принадлежащие только ему подпроекты. MVP допускает ровно один уровень подпроектов без произвольной вложенности и запрещает связь подпроекта с объектами другого независимого проекта.

Каждая новая задача, рекомендация и идея относится ровно к одному независимому проекту и при необходимости к одному его подпроекту. До следующего решения проектом по умолчанию является MetricHit. Существующие legacy-записи автоматически не переназначаются: их scope назначается позднее отдельным проверяемым действием без изменения прежней audit/history.

Глобальная утверждённая память, решения, Strategy и audit не получают project scope. Редакция и другие будущие отделы остаются отдельной категорией автономных бизнес-модулей. Это решение заменяет прежний запрет дочерней иерархии в противоречащей части.
