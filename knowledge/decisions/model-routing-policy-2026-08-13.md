# Политика выбора модели Codex

- Исходное решение: 13.08.2026; дополнено владельцем 15.08.2026.
- Источник: прямое подтверждение владельца MetricHit.

## Модель по умолчанию

Для повседневной работы используется GPT-5.6 Terra с уровнем reasoning Medium.

## Переключение для специальных задач

- GPT-5.3-Codex-Spark используется только для небольших изолированных UI-правок, CSS, текстов интерфейса, узких исправлений и коротких тестовых циклов.
- Spark не используется для архитектуры, SQLite-схем, бизнес-логики, авторизации, security, backup/restore, миграций и больших сквозных модулей.
- Перед сложной архитектурной, security-критичной или особо ответственной задачей Codex предлагает владельцу GPT-5.6 Sol и ждёт явного подтверждения переключения.
- Перед массовой классификацией, извлечением, обработкой большого количества однотипных материалов или фоновыми операциями Codex предлагает GPT-5.6 Luna и ждёт явного подтверждения переключения.
- После завершения специальной задачи Codex предлагает вернуться к GPT-5.6 Terra с reasoning Medium.

Codex не меняет модель самостоятельно: перед любым переключением он уведомляет владельца и ожидает подтверждения.

## Жизненный цикл выбора модели

- Перед каждой новой задачей модель классифицируется заново.
- Разрешение на Sol или Luna действительно только для конкретной задачи либо явно непрерывного этапа и не переносится автоматически на следующую задачу.
- Если текущая модель избыточна для новой задачи, Codex до начала работы предлагает вернуться на Terra Medium.
