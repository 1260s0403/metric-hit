# Решение владельца: количество целевых запросов по объёму публичного материала

- Дата решения: 01.09.2026.
- Источник: прямое указание владельца MetricHit.
- Область: все новые публичные посты и статьи MetricHit, кроме Telegram.

Для каждого нового публичного материала MetricHit вне Telegram считаются уникальные точные целевые запросы из утверждённого не-навигационного семантического ядра из 145 запросов. Основной запрос входит в это количество.

Требуемое количество уникальных целевых запросов по объёму основного текста:

| Объём основного текста | Количество запросов |
| --- | --- |
| 1 800–2 800 знаков | 8–12 |
| 2 801–5 000 знаков | 10–16 |
| 5 001–7 000 знаков | 14–20 |
| 7 001–9 000 знаков | 18–26 |

Один основной точный запрос обязателен в заголовке и первом абзаце. Каждый вторичный точный запрос должен естественно встретиться в основном тексте хотя бы один раз. Все запросы остаются дословными записями утверждённого ядра, без повторов, выдуманных синонимов, LSI-фраз и геовариантов. Материал сохраняет один пользовательский интент и использует один кластер либо несколько документированно смежных кластеров; для геокандидатов по-прежнему нужно предварительное подтверждение спроса. Переспам запрещён.

Для текста короче 1 800 или длиннее 9 000 знаков новые количественные пороги не придумываются: сохраняются все остальные требования, а delivery QA обязательно фиксирует обоснование выбранного количества запросов. Для диапазонов таблицы delivery QA фиксирует фактический объём, число уникальных запросов, их точный список и естественное присутствие вторичных запросов; несоответствие отклоняется fail-closed.

Шкала не применяется к Telegram. Она не меняет архив, существующие черновики, публикации, семантическое ядро, порядок подтверждения публикации или отдельный owner-gate будущей ПФ-кампании.

В противоречащей части это решение уточняет VK-стандарт: для новых VK-постов допускаются один или несколько документированно смежных кластеров с единым интентом, а количество уникальных запросов определяется общей шкалой, а не правилом об одном ключе.

## Уточнение владельца от 05.09.2026

Для полноформатной статьи Oborot минимум сохраняется на уровне 9 000 знаков. Диапазон 7 001–9 000 знаков остаётся ступенью шкалы количества ключей и не является техническим максимумом площадки. Материал свыше 9 000 знаков допустим без произвольного верхнего предела, когда QA фиксирует обоснование количества уникальных точных ключей, их список и естественное присутствие в одном интенте.
