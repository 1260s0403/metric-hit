# Фундамент физического хранилища проектов «Ядра»

- Дата решения: 21.08.2026.
- Источник: прямое утверждение владельца в Strategy-чате.

Первый этап независимых проектных контуров реализует отдельный SQLite-файл для каждого проекта по безопасному детерминированному пути `data/projects/<project_id>/project.sqlite`.

Идентификатор проекта является каноническим UUID версии 4. Выход за корневой каталог, перенаправление пути и совпадение хранилищ запрещены. Файл содержит идентификатор владельца-проекта и версию формата, поэтому повторная инициализация идемпотентна, а чужой, повреждённый или несовместимый файл отклоняется без изменения.

Этап не переносит существующие данные, не меняет действующую базу `data/database/metrichit.db`, не переключает рабочий runtime, не изменяет операторскую панель и не реализует экспорт или импорт. Следующий отдельный этап — безопасная миграция существующих данных после нового утверждения владельца.
