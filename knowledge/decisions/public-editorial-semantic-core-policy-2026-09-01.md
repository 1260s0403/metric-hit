# Решение владельца: семантическое ядро обязательно для всех публичных материалов

- Дата решения: 01.09.2026.
- Источник: прямое подтверждение владельца MetricHit.

Каждый новый публичный пост или статья MetricHit — для VK, Telegram, TenChat, статейных площадок и будущих открытых редакционных каналов — начинается с выбора одного компактного не-навигационного кластера из утверждённого семантического ядра MetricHit из 145 запросов.

Execution card фиксирует выбранный кластер, один основной целевой запрос, пользовательский интент и площадку. Основной запрос естественно расположен в заметной части материала: в H1 статьи либо в заголовке или первом абзаце социального поста. Повторение ключа, ухудшающее читаемость, не допускается.

Материал раскрывает один выбранный интент и не смешивает несвязанные кластеры. Брендовые и навигационные варианты исключены. Геокандидат можно использовать только после предварительного подтверждения спроса.

Перед готовностью нового черновика delivery validation подтверждает выбор кластера, целевой запрос, интент, площадку, естественное заметное размещение запроса, один кластер и проверку спроса для геокандидата. Правило не требует менять уже опубликованный архив и не разрешает публиковать материалы автоматически.
