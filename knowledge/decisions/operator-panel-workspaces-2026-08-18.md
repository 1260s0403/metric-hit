# Утверждённые рабочие экраны operator panel

Дата решения: 2026-08-18.

Для продолжения визуального направления Codex Desktop-like приняты и реализованы три рабочих экрана operator panel. Они используют существующую тёмную монохромную стилистику и не меняют глобальную левую навигацию, кроме отдельного решения перенести «Поиск» в её конец.

- Подпроект получает локальную рабочую область с верхним меню и обзором; это общий шаблон для любого подпроекта, а не только для «Панели».
- «Активность» отображает audit-поток с типовыми вкладками, фильтрами проекта и периода. Открытие подробностей не меняет размеры строк, а панель подробностей занимает выделенную правую область.
- Глобальный «Поиск» использует двухколоночную рабочую область: запрос, фильтры типа/проекта/статуса, сброс, результаты, сортировку и переход к первоисточнику. Все остальные пункты левой навигации сохранены в прежнем порядке; «Поиск» расположен последним.

Проверенные поставки: `f82b183`, `90184ae`, `8a3a2cf`, `7f84099`, `335e336`, `a20c15b`. При проверках UI сценарии отрабатывали; на SERVER некоторые запуски pytest после успешных проверок могут завершаться ошибкой Windows при очистке временного каталога pytest. Это ограничение очистки среды, а не зафиксированная ошибка интерфейса или проверяемого сценария.
