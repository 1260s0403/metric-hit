# Решение владельца: целевые запросы публичных материалов только из утверждённого ядра

- Дата решения: 01.09.2026.
- Источник: прямое уточнение владельца MetricHit.
- Заменяет в противоречащей части редакционное правило от 01.09.2026 о семантическом ядре публичных материалов.

Для каждого нового публичного поста или статьи MetricHit вне Telegram основной целевой запрос и каждый дополнительный (вторичный) целевой запрос выбираются дословно только из утверждённого полного не-навигационного семантического ядра MetricHit из 145 запросов.

Семантика для создаваемой, написанной или уже опубликованной статьи собирается только по тексту самого материала, сохранённому в утверждённой памяти либо локальном editorial-реестре. Для подбора семантики запрещено открывать, посещать или иным образом переходить на публичную страницу уже опубликованной статьи; статус публикации не меняет источник текста и запросов. Каждый выбранный запрос берётся дословно из утверждённой базы семантики в памяти.

Материал может использовать один основной запрос и ноль или несколько вторичных запросов. Запросы могут находиться в одном кластере либо в нескольких смежных кластерах ядра, но только при одном документированном пользовательском интенте. Для нескольких кластеров execution card обязательно фиксирует их полный список и обоснование смежности; delivery QA подтверждает то же обоснование и единый интент. Нельзя смешивать несвязанные кластеры или добавлять запросы другого интента. Переоптимизация запрещена.

Нельзя создавать синонимы, LSI-фразы, геоварианты или иные дополнительные целевые запросы вне утверждённого списка. Обычные неключевые слова и объяснения в естественном тексте разрешены для читаемости, но не считаются, не маркируются и не проверяются как целевые поисковые запросы.

Execution card фиксирует выбранный кластер или полный список смежных кластеров, при необходимости обоснование их смежности, основной запрос, полный список вторичных запросов, один интент, площадку и формат. Compiler и delivery QA fail-closed отклоняют основной или вторичный целевой запрос, если его нет в утверждённом ядре, он не принадлежит одному из зафиксированных кластеров, он повторяется, для нескольких кластеров нет обоснования смежности, либо доказательства не совпадают с card. Брендовые и навигационные варианты по-прежнему исключены; геокандидаты по-прежнему требуют предварительного подтверждения спроса.

Telegram полностью исключён из требований к семантике, целевым запросам, индексации Яндекса и ПФ-цели. Главная цель индексации Яндекса для новых публичных материалов вне Telegram не меняется. Архив и существующие черновики, включая текущий VK-черновик, не переписываются.
