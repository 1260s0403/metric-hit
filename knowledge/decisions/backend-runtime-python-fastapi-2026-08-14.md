# Решение владельца: целевой backend Python/FastAPI

Дата решения: 14.08.2026
Статус: утверждено владельцем

## Решение

- Целевой backend MetricHit OS — Python 3.13 и FastAPI.
- Разработка новой функциональности в Node.js-ядре заморожена.
- Существующее Node.js-ядро сохраняется как эталон совместимости на время миграции.
- SQLite остаётся хранилищем MVP; текущие базы и схемы не мигрируют в рамках этого решения.
- Старое Node.js-ядро может быть удалено только после функционального паритета, прохождения полного набора тестов и отдельного решения владельца.
- Глобальные Python-зависимости запрещены. Зависимости устанавливаются только в проектное окружение `.venv`.

Это решение не разрешает публикацию, резервное копирование или удаление совместимого Node.js-кода.
