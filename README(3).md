# MetricHit Landing

Готовый статический лендинг для публикации через GitHub Pages на домене `go.mtrhit.ru`.

## Структура

- `index.html` — вся разметка, стили и JavaScript лендинга;
- `assets/` — логотипы, кейсы, favicon и Open Graph;
- `404.html` — страница ошибки;
- `robots.txt` и `sitemap.xml` — файлы для поисковых систем.

## Публикация

1. Загрузите всё содержимое этой папки в корень репозитория.
2. В настройках репозитория откройте **Settings → Pages** и выберите публикацию из ветки `main`, папка `/ (root)`.
3. В поле **Custom domain** укажите `go.mtrhit.ru` и после проверки DNS включите **Enforce HTTPS**.

Основная регистрация ведёт на `https://mtrhit.ru/`, поддержка и выдача бонуса — на `https://t.me/Metric_Hit`.
