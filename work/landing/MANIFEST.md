## Аналитика в переданной версии

- В `index.html` установлен один асинхронный счётчик Яндекс Метрики `111490221`.
- Установлен метатег Яндекс Вебмастера `96311327f9a7da8e`.
- Реализована безопасная отправка целей `registration_click`, `login_click`, `support_click`.
- Реализовано чтение `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, хранение в `sessionStorage` и перенос на ссылки MetricHit.
- `registration_complete` не реализована.
- Это последняя рабочая локальная версия: ранее она прошла синтаксическую и сценарную проверку.

## Известные проблемы и последующая правка

1. После создания этой версии владелец уточнил, что `mtrhit.ru` нельзя изменять и основной аналитический запрос — определять источник входа на лендинг плюс считать клики по регистрации.
2. В текущем `index.html` всё ещё присутствуют `login_click`, `support_click` и перенос UTM на ссылки `mtrhit.ru`. Это намеренно не исправлялось при миграции, потому что требовалось упаковать последнюю рабочую версию без изменений.
3. В подвале есть текстовая ссылка «Личный кабинет», хотя владелец позднее сообщил, что основной CTA сайта — только «Регистрация». Требуется отдельное подтверждение владельца перед изменением.
4. Не подтверждено, совпадает ли этот локальный `index.html` с версией, опубликованной в GitHub Pages.
5. Значение `lastmod` в `sitemap.xml` — 2026-08-11; при следующем содержательном обновлении его следует актуализировать.
6. Юридические документы для сайта ранее не предоставлялись и в пакет не входят.

## Инструкция по публикации на сервере

1. Распаковать содержимое каталога `metrichit-landing/` в document root виртуального хоста `go.mtrhit.ru`, сохранив структуру папки `assets/`.
2. Настроить веб-сервер на отдачу `index.html` как index-файла и `404.html` как пользовательской страницы ошибки.
3. Убедиться, что DNS-запись `go.mtrhit.ru` указывает на новый сервер, и установить действующий TLS-сертификат.
4. До переключения DNS проверить сайт через временный host mapping или технический адрес: главную, изображения, кейсы, калькулятор, мобильное меню, ссылки и страницу 404.
5. После публикации проверить доступность:
   - `https://go.mtrhit.ru/`;
   - `https://go.mtrhit.ru/robots.txt`;
   - `https://go.mtrhit.ru/sitemap.xml`;
   - `https://go.mtrhit.ru/assets/og-image.png`;
   - несуществующий URL для проверки `404.html`.
6. Проверить Яндекс Метрику и Вебмастер после смены хостинга. Код счётчика уже находится в `index.html`.
7. Не загружать содержимое архива в document root вместе с внешней папкой-обёрткой, если сервер ожидает `index.html` непосредственно в корне сайта.
